Entrée par scan QR Code Accès Professeur

Sélectionnez la séance (journée + créneau horaire) puis scannez le QR Code du stagiaire. Chaque scan enregistre la présence directement dans la plateforme (feuille d'appel, absences et statistiques) avec la date et l'heure ; un second scan dans la même séance est signalé. Vous pouvez encore corriger un statut à la main puis « Enregistrer ». Saisissez aussi le code manuellement si la caméra n'est pas disponible.
